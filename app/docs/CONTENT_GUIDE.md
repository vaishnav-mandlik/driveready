# Content guide — questions & lessons

All learning content is bundled JSON under `src/content/`. It must be **accurate,
sourced from official material, and original** (never copied from other apps or
verbatim from official sample tests).

## Files

| What | Path | Notes |
|---|---|---|
| Universal car questions | `src/content/questions/car/<topic>.json` | Valid in **all 50 states + DC** |
| Universal motorcycle questions | `src/content/questions/motorcycle/<topic>.json` | MSF Motorcycle Operator Manual based |
| Universal CDL questions | `src/content/questions/cdl/<topic>.json` | AAMVA model CDL manual / FMCSA rules |
| State-specific questions (all tracks) | `src/content/questions/states/<XX>.json` | Every item has `"states": ["XX"]` |
| State info (test format, verified facts) | `src/content/states/<XX>.json` | Generated by `scripts/import-state-facts.mjs` |
| Lessons | `src/content/lessons/<track>/<id>.json` | One file per lesson |
| Signs | `src/content/signs/index.ts` + `_codes.json` | Generated; reference signs by `code` |

After adding/removing files run `npm run content:index`. Always run
`npm run content:check` (or `node scripts/validate-content.mjs <files>`) — it must
report **0 errors**.

## Question format

```json
{
  "id": "car.row.014",
  "track": "car",
  "topic": "right-of-way",
  "prompt": "Two vehicles reach an uncontrolled intersection at the same time. Who should yield?",
  "choices": [
    "The driver on the left yields to the driver on the right",
    "The driver on the right yields to the driver on the left",
    "The faster vehicle goes first",
    "The larger vehicle goes first"
  ],
  "answer": 0,
  "explanation": "When two vehicles arrive at the same time, the driver on the left yields to the driver on the right.",
  "difficulty": 1,
  "ref": "Common to state driver handbooks (right-of-way)"
}
```

- `id`: lowercase, stable forever, unique across the app. Universal: `<track>.<topicabbr>.<nnn>`
  (e.g. `car.row.014`, `mc.gear.003`, `cdl.ab.021`). State: `<xx>.<track>.<nnn>` (e.g. `tx.car.007`).
- `choices`: 2–4 options (use 4 whenever sensible; 3 is fine when only 3 plausible options exist;
  True/False only with `"lockOrder": true`). Choices are shuffled in the app.
- `answer`: index of the single correct choice.
- `explanation`: 1–3 sentences, states the rule (include the key number) and, when useful, why the
  most tempting wrong answer is wrong.
- `sign`: optional sign code from `src/content/signs/_codes.json` — the image is shown above the prompt.
  Never name the sign in the prompt when the question is "what does this sign mean?".
- `states`: only on state-specific questions.
- `difficulty`: 1 = recall of a basic rule, 2 = applying a rule / specific number, 3 = tricky
  scenario, exception, or commonly-confused rule.
- `ref`: human-readable source (handbook title + page for state questions).

## Accuracy rules (non-negotiable)

1. **One defensible correct answer.** If an expert could argue for two options, rewrite.
2. **Grounded.** Every fact must be supported by an official handbook/manual or statute.
   State questions: the state's own handbook or verified facts only.
3. **Universal means universal.** A universal question must be correct in every state + DC.
   Numbers that vary by state (BAC under 21, parking distances, following-distance seconds,
   signaling distance, headlight timing, speed limits, school-bus rules on divided highways,
   turn-on-red details, phone laws, GDL rules, insurance, points, crash-report thresholds,
   lane splitting, helmet laws...) belong in **state** files, never universal ones.
   The legal adult BAC limit is 0.08% everywhere **except Utah (0.05%)** — so it is state-specific.
4. **No trick wording.** Avoid double negatives. "NOT"/"EXCEPT" questions are allowed sparingly and
   must capitalize the word.
5. **Plausible distractors.** Wrong options should be realistic mistakes (nearby numbers, common
   misconceptions), never jokes or obviously absurd choices.
6. **No order-dependent choices** ("all of the above", "both A and B") unless `"lockOrder": true`.
7. **Original wording.** Do not copy questions from other apps, websites or official sample tests.
8. **Plain language.** ~8th-grade reading level; prompts ≤ 2 sentences when possible.
9. **No duplicates.** Don't ask the same fact the same way twice; different angles are good.

## Lessons

`Lesson` objects (see `src/data/types.ts`): concise, scannable study notes for one topic.
Sections of blocks: `p`, `bullets`, `steps`, `tip`, `warning`, `sign`/`signs` (by code), `table`
(`[label, value]` rows). Finish with 4–8 `keyPoints`. Universal lessons must not state
state-specific numbers; instead say "check your state's rule in the State Cheat Sheet".
